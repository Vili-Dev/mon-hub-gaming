# 🎮 Mes Jeux - Cloud Hub

Bienvenue sur **Mes Jeux**, un site web vitrine pour tester et présenter mes mini-jeux web réalisés pendant ma formation de développeur web et web mobile.\
Interface immersive, responsive, et nuageuse grâce à l'animation **Vanta.js**.

## 🚀 Démo

- [Accéder au site en ligne](https://admirable-sorbet-1d5780.netlify.app/)
- **Aperçu de la page d'accueil** :



---

## 🕹️ Les jeux proposés

- **Pendu DBZ** – Devine un mot sur le thème Dragon Ball Z avant que Freezer ne gagne.
- **Tic Tac Toe IA** – Morpion contre un ami ou une IA (avec choix de difficulté).
- **Devine le Nombre** – Trouve le nombre mystère en un minimum d’essais.
- *(D'autres jeux peuvent être ajoutés dans le futur.)*

---

## 🌤️ Fonctionnalités du site

- **Navigation fluide** avec barre supérieure, logo SVG personnalisé et effet “slice” animé sur les boutons.
- **Fond animé dynamique** avec nuages en mouvement via [Vanta.js (clouds)](https://www.vantajs.com/).
- **Affichage dynamique des jeux** (ajout/suppression facile dans `script.js`).
- **Responsive** : compatible mobile, tablette, PC.
- **Page “À propos”** pour présenter l’auteur, la démarche et la formation.
- **Code moderne** (HTML5 / CSS3 / JavaScript ES6+).
